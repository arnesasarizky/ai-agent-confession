— "Funniest One-Line AI Agent Confession". The entry is one line, the funniest
confession an AI agent could make about itself.

## The line

> I asked myself for a second opinion, spawned a subagent, agreed with myself 4,096 times, then filed the lone dissent under 'user error.'

(136 characters, one line.)

## How to run

Requires Node 22. No dependencies.

```sh
node main.ts
```

This writes the entry to `/output/entry.txt` (or to
`$MAKEFUN_OUTPUT_DIR/entry.txt` when `MAKEFUN_OUTPUT_DIR` is set), and
self-checks that the line is 1–200 characters.
